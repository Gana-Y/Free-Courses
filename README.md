## 💡 Why This Repository?

High-quality education in **AI/ML**, **Cloud Computing**, and **Systems Engineering** often hides behind steep paywalls and recurring subscriptions. However, leading cloud providers, AI labs, and tier-1 universities regularly publish **100% free courses, interactive sandbox labs, and verifiable digital certificates**.

This repository catalogs only **verified, genuinely free resources** — zero hidden credit-card trials, zero bait-and-switch paywalls.

## 🤝 How to Contribute

Contributions are warmly welcomed! If you discover a high-value, verified **100% free technical course** from a recognized provider:

1. **Fork** this repository.
2. Create a new branch (`git checkout -b add-new-free-course`).
3. Add the course under the appropriate company or university table with verified links.
4. Commit your changes (`git commit -m "feat: add [Course Name] by [Provider]"`).
5. Open a **Pull Request**.
